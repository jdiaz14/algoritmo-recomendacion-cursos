# Algoritmo de Recomendación de Cursos

## Descripción

Este proyecto desarrolla un algoritmo básico de recomendación de cursos basado en las preferencias de los usuarios.

El programa presenta dos cursos seleccionados al azar y solicita al usuario que elija cuál de ellos prefiere. El proceso se repite varias veces y las elecciones son registradas para determinar cuáles cursos obtuvieron mayor cantidad de votos.

## Objetivo

Construir un algoritmo sencillo que permita identificar los cursos más recomendados a partir de las decisiones de los usuarios.

## ¿Cómo funciona?

El algoritmo sigue los siguientes pasos:

1. Se crea una lista de cursos disponibles.
2. Se seleccionan dos cursos de manera aleatoria.
3. Se muestran los dos cursos al usuario.
4. El usuario selecciona la opción que prefiere.
5. El sistema registra un voto para el curso seleccionado.
6. El proceso se repite 10 veces.
7. Finalmente, los cursos se organizan de acuerdo con la cantidad de votos obtenidos.
8. El curso con mayor cantidad de votos se presenta como el más recomendado.

## Resultado

Al finalizar las 10 comparaciones, el algoritmo muestra un ranking de los cursos según la cantidad de votos obtenidos e identifica el curso más recomendado.
